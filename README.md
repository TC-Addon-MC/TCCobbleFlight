# TC Cobble Flight
A Fabric mod that adds dynamic flight behavior to wild Flying-type Pokémon in Cobblemon. Pokémon will naturally take off, cruise, and land based on their type, weight, and surrounding environment.
## Setup

For setup instructions, please see the [Fabric Documentation page](https://docs.fabricmc.net/develop/getting-started/creating-a-project#setting-up) related to the IDE that you are using.
